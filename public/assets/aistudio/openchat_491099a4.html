Send a message with curl

Put your own username in user_name. A request that tries to send as somebody else is rejected with HTTP 403.

curl --get "https://YOUR-OPENCHAT-URL/api/send" \
  --data-urlencode "api_openchat_id=YOUR_KEY" \
  --data-urlencode "user_name=YOUR_USERNAME" \
  --data-urlencode "text=Hello from curl"

Messages go to openchat/general by default. If you belong to another server, add server_id and channel_id.
